Install

One command. About a minute.

It installs Threadline, connects the agents it finds, and turns on pick-up at the start of each chat. Restart your agents once afterwards.

Questions

Does my history leave my computer?

No. The journal lives in a folder in your home directory. The page at threadline-409ee.web.app reads it straight from your computer through a small local server that only answers that page, with a secret that changes every time you run threadline open. The only exception is the cloud fallback: if Gemini Nano can't run, the messages being read go to Gemini in Google's cloud, and the page says so.

Do I need an account or an API key?

No. There is nothing to sign up for and nothing to paste in.

What does Gemini Nano need?

Chrome on a recent computer with enough memory and free disk space. Chrome downloads the model once and the page shows the progress. Until then, or if your computer can't run it, the page uses the cloud.

Do my agents have to support Threadline?

No. Threadline reads the chats each agent already saves on your computer and connects to each agent through MCP, the standard way agents use tools.

Is it free?

Yes. Threadline is open source under the MIT license.
